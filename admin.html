How do I get an access key? (one time, 2 min)
  1. Open github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name: Portfolio admin. Expiration: choose what you like (e.g. 1 year).
  3. Repository access → Only select repositories → pick PranVeda.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Click Generate token, copy it and paste it above.
